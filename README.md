# 日常 · 工作与生活

一个只在本机浏览器中使用的个人工作生活 App。页面文件由本机小型服务提供，服务只监听 `127.0.0.1`；业务数据由你选择的独立 JSON 文档保存，不会上传。

## 在这台电脑上打开

1. 双击 `Launch-App.bat`（也可以双击中文文件名的 `启动App.bat`）。
2. 浏览器会打开本机 App。首次使用时，选择“创建新数据文件”，并选定独立 JSON 文件的保存位置；以后变更会自动保存。
3. 保持启动窗口打开，关闭窗口即可停止本机服务。下次再双击启动器即可继续使用；浏览器如要求授权，选择“重新授权”并连接同一数据文件。

请使用最新版 Microsoft Edge 或 Google Chrome，以支持直接读写本地文件。使用浏览器“刷新”、关闭浏览器或重启电脑不会删除独立数据文件。

## 备份与恢复

- 在“数据与设置”中选择“保存备份文件”，把完整数据保存成独立 JSON 文档。建议定期把备份复制到你选择的本机位置。
- 恢复时选择一个备份。App 会先校验文件并展示其中的记录数量。
- 确认恢复后，再选择恢复前安全备份的保存位置。安全备份成功写入后，App 才会替换当前主数据文件。
- 无效或版本不兼容的文件不会替换当前数据。

## 开发与测试

项目使用 React、TypeScript 和 Vite。需要 Node.js 24 或更高版本以及 pnpm。Windows 启动入口由 `Launch-App.bat` 调用同目录中的 `Launch-App.ps1` 提供页面服务。

```powershell
pnpm install
pnpm run build
pnpm test
```

`pnpm run build` 生成 `dist/`。启动器读取该目录；源码有改动后需重新构建再打开 App。
